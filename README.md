# 💳 Credit Card Transaction Analysis (SQL + Power BI)

## 📊 Project Overview
This project analyzes 26K+ credit card transactions to uncover business insights related to spending patterns, customer behavior, and revenue contribution.

## 🎯 Business Problems Solved
- Top 5 cities contributing to total spend
- Monthly spending trends by card type
- Highest MoM growth identification
- Gender-based spend contribution
- Weekend spending behavior analysis
- High-value transaction tracking

---

## 🛠️ Tools & Technologies
- SQL (Data Analysis)
- Power BI (Dashboard & Visualization)
- DAX (Measures & Calculations)

---

## ⚙️ Key Features
- Interactive 3-page Power BI dashboard
- Advanced SQL queries using window functions
- Data cleaning and transformation
- Business-focused insights
